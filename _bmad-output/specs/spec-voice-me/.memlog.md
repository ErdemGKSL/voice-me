- (capability) CAP-1 Voice Setup - intent: user records own voice in-app or imports an audio file as their Reference Voice Sample - success: clip saved and selectable as active sample; re-record/replace anytime (from PRD FR-1)
- (capability) CAP-2 Background/tray operation - intent: app runs as a background/tray-resident process, always ready for the next hotkey - success: after dismissing the Prompt Overlay the app stays active without relaunch, reachable via tray presence (from PRD FR-2)
- (capability) CAP-3 Global hotkey configuration - intent: user assigns/changes one global hotkey that summons the Prompt Overlay from anywhere, including in-game - success: works with a fullscreen/borderless game focused on Linux and Windows; an already-used combo is surfaced, not silently dropped (from PRD FR-3)
- (capability) CAP-4 Prompt Overlay summon/type/dismiss - intent: hotkey opens a minimal overlay, Enter closes it instantly and triggers speaking the typed line, Escape cancels - success: overlay appears without perceptible delay, closes immediately on Enter before generation completes, Escape/focus-loss discards the text (from PRD FR-4)
- (capability) CAP-5 TTS generation via cloned voice - intent: typed text + active Reference Voice Sample + selected language produce spoken audio in the user's own voice - success: generated audio matches the selected speech language; a generation failure surfaces clearly, never silent failure (from PRD FR-5)
- (capability) CAP-6 Playback through the Virtual Microphone - intent: generated audio plays through a Virtual Microphone device other apps can select as mic input - success: an app selecting the Virtual Microphone on Linux or Windows receives the audio timed to the Speak Action; the real physical mic is untouched (from PRD FR-6)
- (capability) CAP-7 Dependency Check and provisioning - intent: app detects missing local runtime dependencies and offers one-click provisioning in its own UI - success: a missing dependency is named specifically with a one-click fix or clear manual steps; degrades to CPU-only mode rather than failing without a GPU (from PRD FR-7)
- (capability) CAP-8 Turkish/English UI - intent: interface available in Turkish and English, independent of TTS speech language - success: switching UI language takes effect without restart; UI and speech language can differ (from PRD FR-8)
- (capability) CAP-9 Modern, clean visual design via gpui-kit - intent: whole interface built with gpui-kit components, following its Design Guides - success: standard UI elements are gpui-kit components; visual decisions checked against gpui-kit-design-guides (from PRD FR-9)
- (constraint) Local-only inference; no cloud calls, no accounts, no telemetry - network egress is limited to voice-me-deps's declared dependency fetches (PRD, spine AD-8)
- (constraint) v1 targets Linux and Windows only; macOS explicitly deferred (PRD scope)
- (constraint) Free and open source; GitHub Actions CI (separate Linux/Windows build jobs), distribution and runtime-asset hosting via this repo's own GitHub Releases (PRD, spine AD-7)
- (constraint) UI implemented with gpui-kit components, not raw GPUI primitives; visual design follows gpui-kit-design-guides (PRD FR-9)
- (constraint) Rust workspace on the hexagonal/ports-and-adapters paradigm; per-OS capabilities (hotkey, virtual mic, tray) ship as separate crates; single AppState/AppEvent ownership model - full detail in the adopted Architecture Spine companion (spine AD-1, AD-2, AD-3)
- (decision) Non-goal: live, continuous voice-changing - this is discrete typed-line playback, not real-time voice pass-through
- (decision) Non-goal: macOS support in v1
- (decision) Non-goal: Preset Phrase (hotkey bound directly to a fixed spoken phrase, no overlay) in v1 - planned for a later version
- (decision) Non-goal: cloud or hybrid inference
- (decision) Non-goal: accounts, licensing, monetization
- (decision) Non-goal: speech languages beyond what Chatterbox-Multilingual V3 supports natively
